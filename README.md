# Muse

私人仓库，存放专门为我定制的 3 个 Muse skill（2026-11-11 整理）。

| 文件夹 | 是什么 | 原本地名 |
| --- | --- | --- |
| `math-olympiad-tutor/` | 小学奥数辅导：出题、讲题、批改、错题复习 | `local-math-olympiad-tutor` |
| `stock-monitor/` | 持仓股票监控：实时行情、公告、异动提醒 | `local-stock-monitor` |
| `life-decision-guide/` | 人生决策指南：《高性价比人生指南》全文与索引 | `local-life-decision-guide` |

说明：

- 每个 skill 一个文件夹，里面有 `SKILL.md`（说明文件）和 `skill.yaml`。
- 奥数辅导的 `progress.md`（儿子正在用的错题本）没有放进来，那是每天都在变的工作文件，不属于 skill 本身。
- 仓库是 Private 私有，只有账号本人能看到。
- 以后 skill 更新了，再推一次新版本，GitHub 会留着每次改动的记录，改坏了能找回以前的版本。
